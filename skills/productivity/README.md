# Productivity

General workflow tools, not code-specific.

## User-invoked

- **[chill-me](./chill-me/SKILL.md)** — A capped grilling session: ask only the top N questions (default 3), assume the rest, then start a goal.

## Model-invoked

- **[switching-codex-accounts](./switching-codex-accounts/SKILL.md)** — When a Codex run Claude launched fails with Codex's usage-limit error, rotate the active `codex-auth` account round-robin and rerun the command, trying each account once before reporting reset times.
