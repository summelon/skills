# Engineering

Skills for daily code work.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[logging-issues](./logging-issues/SKILL.md)** — Log nontrivial issues into `docs/issues/` as they're solved: context, root cause, repro, pinned environment. Sweeps at milestone end; recalls past entries when a new error looks familiar.
- **[aligning-targets](./aligning-targets/SKILL.md)** — Seal a contract on a milestone's targets and a mock of the final verification report before implementation; fill the same skeleton with real evidence at the end.
